# AltaIDE standalone prototype

Интерактивный standalone-прототип AltaIDE по Figma-узлам `21127:451709` и `21130:521108`.

## Запуск

Откройте `prototype.html` напрямую в современном браузере. Установка зависимостей и локальный сервер не требуются.

## Возможности

- переход `initial → compiling` по кнопке Compile;
- устойчивое состояние Compile `Default → Pressed`, включая Enter и Space;
- изменение ширины Sidebar;
- изменение высоты нижней панели;
- переключение вкладок;
- выбор элементов дерева проекта;
- внутренний scroll таблицы и дерева;
- клавиатурное управление разделителями;
- локальные SVG-иконки и шрифты без внешних зависимостей.

## Проверенные размеры

- 1200 × 800;
- 1364 × 900 — основной Figma reference;
- 1600 × 1000;
- 1920 × 1080.

На всех размерах приложение занимает viewport, панели не перекрываются, а таблица не растягивает страницу.
